# Infinite Canvas 图片拆分与合并节点插件

这是 [Infinite Canvas（无限画布）](https://github.com/tigerowo/infinite-canvas) 的一个第三方节点插件，用于拆分（切割）图片或把多张图片合并（拼接）成一张大图。

## 功能

### 拆分（切割）

- **网格均分**：把一张图均匀切成 N×M 的网格（如 2×2、3×3），每块回传为独立图片节点。
- **自定义图框**：在预览图上用鼠标拖拽绘制矩形框，可以拉多个框，按绘制顺序依次拆出图片。

### 合并（拼接）

- **网格拼接**：把多张图片拼接成网格大图。
- **分割线**：支持自定义分割线颜色与宽度。
- **自动标注图号**：每块自动标注 1、2、3… 的图号。
- **字号可调**：标注文字字号可调（8–64px）。
- **自动换行与行距自适应**：批注文字较多时按宽度自动换行，行距随字号自适应。
- **节点内图片管理**：节点内即可预览每张参与合并的图；左下角有序号（删除后自动更新），右上角悬停显示删除按钮；单击图片放大单独预览，并在下方文本框添加批注。

### 文字标注 / 涂鸦（0.3.0 新增）

- **全屏编辑器**：点击「打开标注编辑器」进入，画布覆盖整个窗口，不受节点尺寸限制。
- **工具**：自由画笔、箭头、方框、文字标注、橡皮（拖过删除整笔）。
- **可调项**：颜色、画笔粗细、文字字号、文字底色开关。
- **编辑操作**：撤销上一步、一键清空。
- **导出**：按**原图分辨率**生成 PNG（不是截图缩放），预览后可一键回传画布。
- 所有坐标按图片比例（0..1）保存，编辑器缩放与导出结果不会错位。

### 图片来源（0.3.0 重写为通用适配层）

- 普通图片节点、全景图节点。
- **豆包生图等宿主渠道的自定义类型节点**：不再依赖 `node.type === "image"`。
- **批量生成节点**：自动展开 `batchChildIds` 子节点，一次生成的多张图全部纳入。
- **间接上游**：沿连线向上穿透 2 层（豆包节点 → 中间节点 → 本节点 也能识别）。
- 地址字段白名单：`content` / `imageUrl` / `url` / `images[]` / `results` / `storageKey` 等。
- 本地导入图片。
- 节点内提供「**上游诊断 / 重新扫描**」：显示识别到几张、来自哪个节点、节点类型、加载失败原因。豆包重新生成导致地址变化时会自动重扫。

## 安装方式

在画布右上角「节点插件 → 第三方插件」中粘贴以下地址安装：

```text
https://cdn.jsdelivr.net/gh/wudidekongjv/-Image-Split-and-Merge-Node-@main/dist/image-split-merge.js
```

> 提示：jsDelivr 的 `@main` 有 CDN 缓存，发布新版本后可能延迟几分钟生效。如需立即获取某个具体版本，可把 `@main` 换成具体 commit。

安装后，画布创建菜单中会出现「🧩 图片拆分与合并」节点。

## 使用步骤

### 拆分

1. 创建「图片拆分与合并」节点，导入图片或连接上游图片节点。
2. 选择「网格均分」（填行列数）或「自定义图框」（在图上拖拽画框）。
3. 点击「执行拆分」预览结果。
4. 点击「回传 N 张切片到画布」。

### 合并

1. 连接多张上游图片节点（或导入）。
2. 在节点内的图片列表中：单击某张图可放大预览并添加批注；悬停右上角可删除某张图（序号自动更新）。
3. 设置每行列数、分割线颜色/宽度、标注字号、是否标注图号。
4. 点击「执行合并」预览，再点击「回传拼接图到画布」。

### 标注 / 涂鸦

1. 在「🎨 文字标注 / 涂鸦」区的下拉框选择要标注的图片（默认第一张）。
2. 点「打开标注编辑器」，选工具后在图上拖拽 / 点击。
3. 文字工具：点击放置位置，输入文字后回车（支持换行）。
4. 点「生成标注图预览」，确认后「回传标注图到画布」。

## 构建与自测

```bash
npm install
npm test        # 25 项回归：上游节点适配 15 项 + 编辑器 DOM 10 项
node build.mjs  # 产物 -> dist/image-split-merge.js
```

插件产物是 `dist/image-split-merge.js`，不依赖宿主源码、不打包第二份 React、无第三方运行时依赖（原生 `<canvas>` 处理）。

## 技术说明

- **拆分引擎**：`<canvas>` 的 `drawImage` 按区域裁剪。
- **合并引擎**：`<canvas>` 将多图缩放拼接到网格，用 `fillRect` 绘制分割线与标注底、`fillText` 绘制图号与批注。
- **标注引擎**：笔迹 / 箭头 / 方框 / 文字统一用归一化坐标存储，绘制时乘以原图宽高；橡皮按距离删除整笔；导出走一张与原图等尺寸的离屏 canvas。
- **浮层挂载**：画布层和节点层均带 `transform`，`position: fixed` 会被限制在节点内，因此编辑器用原生 DOM 挂到 `document.body`（与导演台插件一致）。
- **图片源解析**：`data:` / `blob:` / 远程 http(s) URL / `https://canvas-assets/...` / `storageKey`。远程地址优先 fetch 成 blob（保证 canvas 可导出）；跨域被 CORS 拦截时退回原地址交给 `<img>` 尝试，并给出「画布被污染」的可执行提示。宿主桥接对象依次尝试 `hushifuHost` / `canvasHost` / `__CANVAS_HOST__` / `storyaiHost`。
- **逐张容错**：上游任一张图加载失败不再中断整批，失败原因写进「上游诊断」。

远程插件代码会在画布页面内执行，请只安装自己信任的发布地址。
