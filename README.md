# Infinite Canvas 图片拆分与合并节点插件

这是 [Infinite Canvas（无限画布）](https://github.com/tigerowo/infinite-canvas) 的一个第三方节点插件，用于拆分（切割）图片或把多张图片合并（拼接）成一张大图。

## 功能

### 拆分（切割）

- **网格均分**：把一张图均匀切成 N×M 的网格（如 2×2、3×3），每块回传为独立图片节点。
- **自定义图框**：在预览图上用鼠标拖拽绘制矩形框，可以拉多个框，按绘制顺序依次拆出图片。

### 合并（拼接）

- **网格拼接**：把多张图片拼接成网格大图。
- **分割线**：支持自定义分割线颜色与宽度。
- **自动标注图号**：每块自动标注 1、2、3… 的图号。
- **字号可调**：标注文字字号可调（8–64px）。
- **自动换行与行距自适应**：批注文字较多时按宽度自动换行，行距随字号自适应。
- **节点内图片管理**：节点内即可预览每张参与合并的图；左下角有序号（删除后自动更新），右上角悬停显示删除按钮；单击图片放大单独预览，并在下方文本框添加批注。

### 图片来源

- 连接上游图片节点自动识别。
- 节点内导入本地图片。

## 安装方式

在画布右上角「节点插件 → 第三方插件」中粘贴以下地址安装：

```text
https://cdn.jsdelivr.net/gh/wudidekongjv/-Image-Split-and-Merge-Node-@main/dist/image-split-merge.js
```

> 提示：jsDelivr 的 `@main` 有 CDN 缓存，发布新版本后可能延迟几分钟生效。如需立即获取某个具体版本，可把 `@main` 换成具体 commit。

安装后，画布创建菜单中会出现「🧩 图片拆分与合并」节点。

## 使用步骤

### 拆分

1. 创建「图片拆分与合并」节点，导入图片或连接上游图片节点。
2. 选择「网格均分」（填行列数）或「自定义图框」（在图上拖拽画框）。
3. 点击「执行拆分」预览结果。
4. 点击「回传 N 张切片到画布」。

### 合并

1. 连接多张上游图片节点（或导入）。
2. 在节点内的图片列表中：单击某张图可放大预览并添加批注；悬停右上角可删除某张图（序号自动更新）。
3. 设置每行列数、分割线颜色/宽度、标注字号、是否标注图号。
4. 点击「执行合并」预览，再点击「回传拼接图到画布」。

## 构建

```bash
npm install
node --check src/image-split-merge.js   # 语法检查
node build.mjs                          # 产物 -> dist/image-split-merge.js
```

插件产物是 `dist/image-split-merge.js`，不依赖宿主源码、不打包第二份 React、无第三方运行时依赖（原生 `<canvas>` 处理）。

## 技术说明

- **拆分引擎**：`<canvas>` 的 `drawImage` 按区域裁剪。
- **合并引擎**：`<canvas>` 将多图缩放拼接到网格，用 `fillRect` 绘制分割线与标注底、`fillText` 绘制图号与批注。
- **图片源解析**：支持 `data:` / `blob:` / 远程 http(s) URL；对 `https://canvas-assets/...` 虚拟主机地址，会自动走宿主 `window.hushifuHost.materialDataUrl()` 通道获取可加载数据。

远程插件代码会在画布页面内执行，请只安装自己信任的发布地址。
